Immich Photos Album

Display images from an album on your Immich server.

Connect InkyPi to your self-hosted Immich instance, select an album, and choose how photos are selected and framed for your e-paper display.

API key setup

In Immich, create an API key with access to the album and its images. Then open InkyPi’s API Keys page using the key icon, add a key named IMMICH_API_KEY, paste the Immich API key as its value, and save it.

☁
Immich connection
Enter the server address and select the album you want to display.

Use the address that the InkyPi device can reach on your network.

Open the album in Immich and copy the UUID at the end of the browser URL.

🖼️
Image selection
Control which photo is chosen from the configured Immich album.

The plugin uses image assets only and ignores videos.

Increase this if your server or network responds slowly.

⚙
