Immich Photos Album

Display images from an album on your Immich server.

Connect InkyPi to your self-hosted Immich instance, select an album, and choose how photos are selected and framed for your e-paper display.

☁
Immich connection
Enter the server address and the album you want to display.

Use the URL or local hostname that your InkyPi device can reach.

Open the album in Immich and copy the UUID found at the end of its browser URL.

🔑
Immich API key
Keep the API key in InkyPi’s API Keys list instead of in plugin settings.

Add your Immich API key to InkyPi’s API Keys list using this exact name. The default is IMMICH_API_KEY.

API key setup

In Immich, create an API key with access to the album and its images. Then open InkyPi’s API Keys page using the key icon, add a key named IMMICH_API_KEY, paste the Immich API key as its value, and save it. If you use a different name, enter that same name in the field above.

🖼️
Image selection
Control which photo is chosen from the configured Immich album.

Videos are ignored; only image assets in the album are used.

Increase this if your Immich server or network responds slowly.

⚙

Fill crops to cover the display, while contain keeps the entire image visible.

Show or hide the caption bar at the bottom of the display.

Choose what appears in the caption area when captions are enabled.

Adds a border around the rendered photo.

Border thickness in pixels when the border is enabled.

Can help images read more clearly on e-paper displays.
